title: Command line
description: The cornercase command, its subcommands and the messages it can stop with.
---

cornercase has a deliberately small command line. Everything else happens in the app.

## Commands

```sh
cornercase              # open the UI, starting the server if needed
cornercase kill-server  # stop the server and every shell in it
```

### `cornercase`

Attaches to the server, starting it first if none is running. A new server restores your [saved session](../../guides/sessions/#what-is-restored), or, when there is nothing to restore, opens the folder you ran the command from as a project.

When it starts, the client asks your terminal for its colours (it waits at most a second for the answer), then turns on mouse reporting, bracketed paste and unambiguous key reporting. It puts your terminal back the way it was when it exits.

### `cornercase kill-server`

Stops the server: every shell and program in every pane ends, and every attached client exits. It waits for the server to be gone before returning. If no server is running on the socket, it prints `no cornercase server is running`.

### `cornercase server`

Runs the server itself. You don't need it: `cornercase` starts it in the background for you, with its output going to `server.log` next to the socket. It is listed here so you recognise it in your process list.

## The socket

All three commands find the server through the same socket: `CORNERCASE_SOCKET` if it is set, otherwise `$XDG_RUNTIME_DIR/cornercase/server.sock` or `$TMPDIR/cornercase-<uid>/server.sock`. Set `CORNERCASE_SOCKET` on every command to work with a [separate server](../../guides/sessions/#a-separate-server):

```sh
CORNERCASE_SOCKET=/tmp/cc-demo/server.sock cornercase
CORNERCASE_SOCKET=/tmp/cc-demo/server.sock cornercase kill-server
```

## Messages

| Message | Meaning |
| --- | --- |
| `cornercase is already running in this terminal; nesting it is not supported` | You ran `cornercase` inside one of its own panes. Use another terminal. |
| `the running cornercase server comes from another build. Run cornercase kill-server (it closes all its terminals) and start cornercase again` | You updated or rebuilt cornercase while the old server kept running. |
| `the running cornercase server is incompatible with this build. Run cornercase kill-server …` | Same cause, detected while talking to the server. |
| `failed to start the cornercase server; see <log>` | The server didn't come up within a few seconds. The log next to the socket says why. |
| `a cornercase server is already running on <socket>` | Printed by `cornercase server` when another server holds the socket's lock. |
| ``unknown command `…`; use `cornercase` or `cornercase kill-server` `` | Only those two forms exist. |

On any of these, `cornercase` exits with a non-zero status.
